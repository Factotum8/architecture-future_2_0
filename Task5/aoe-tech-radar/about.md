# О техническом радаре «Будущее 2.0»

Этот радар отражает **целевой технологический ландшафт** и **архитектурные паттерны** компании на горизонте преобразований (облако, события, доменные данные, вывод легаси).

## Как читать

- **Квадранты** — области: языки, платформы, инструменты, методы и паттерны.
- **Кольца** — зрелость и рекомендация:
  - **Adopt** — брать в стандарт для новых решений.
  - **Trial** — пилотировать в ограниченном контуре.
  - **Assess** — изучать, PoC.
  - **Hold** — не развивать; сопровождение или поэтапный вывод.

## Источник данных

Список блипов синхронизирован с `../tech-radar.json` в репозитории курсовой работы. При изменении JSON перегенерируйте или обновите соответствующие файлы в `radar/<дата>/`.

## Запуск локально

Из каталога `aoe-tech-radar`:

```bash
npm install
npm run serve
```

Откройте в браузере путь с учётом `basePath` из `config.json` (по умолчанию `/techradar`).
